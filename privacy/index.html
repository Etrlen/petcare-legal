Политика конфиденциальности приложения Pet Care: с заботой о питомцах

Дата вступления в силу: 26 сентября 2026 года

Pet Care: с заботой о питомцах — приложение для хранения информации о питомцах, событиях ухода и напоминаниях.

Разработчик: etrlen
Контактный email: support@petcare-app.ru

Какие данные обрабатывает Pet Care: с заботой о питомцах

Pet Care: с заботой о питомцах может обрабатывать следующие данные:

  • адрес электронной почты — если вы создаёте аккаунт;
  • данные о питомцах, которые вы добавляете самостоятельно;
  • информацию о вакцинациях, обработках и других событиях ухода;
  • названия препаратов;
  • даты выполнения и запланированные даты событий;
  • настройки напоминаний;
  • технические данные, необходимые для работы авторизации, облачной синхронизации и сетевых запросов.

Создание аккаунта необязательно. Основными функциями Pet Care: с заботой о питомцах можно пользоваться без регистрации.

Локальное хранение

Данные о питомцах и событиях сначала сохраняются непосредственно на вашем устройстве.

Если вы используете Pet Care: с заботой о питомцах без аккаунта, эти данные не передаются в облачное хранилище Pet Care: с заботой о питомцах.

Удаление приложения или очистка его данных средствами операционной системы может привести к удалению локальных данных.

Аккаунт и облачная синхронизация

Если вы создаёте аккаунт, Pet Care: с заботой о питомцах использует ваш email для авторизации и синхронизации данных между устройством и облачным хранилищем.

При использовании аккаунта в облаке могут храниться:

  • данные питомцев;
  • события ухода;
  • информация о выполненных событиях;
  • изменения запланированных дат;
  • другие данные приложения Pet Care: с заботой о питомцах, необходимые для синхронизации.

Для авторизации и облачного хранения используется Supabase.

Пароли обрабатываются системой авторизации Supabase. Pet Care: с заботой о питомцах не хранит пароль пользователя в открытом виде.

Системные письма

Pet Care: с заботой о питомцах отправляет только письма, необходимые для работы аккаунта, например подтверждение адреса электронной почты и восстановление пароля.

Для доставки таких писем используется RuSender. Для отправки письма сервис получает адрес электронной почты получателя и содержимое системного письма.

Pet Care: с заботой о питомцах не использует email для рекламных рассылок.

Передача данных третьим лицам

Pet Care: с заботой о питомцах не продаёт персональные данные пользователей и не использует их для рекламного профилирования.

Данные могут передаваться поставщикам инфраструктуры только в объёме, необходимом для работы приложения, в частности:

  • Supabase — для авторизации и облачной синхронизации;
  • RuSender — для доставки системных писем;
  • поставщику почтовой инфраструктуры — при обращении пользователя в поддержку по электронной почте.

Такие сервисы обрабатывают данные в соответствии со своими условиями и политиками конфиденциальности.

Реклама и аналитика

Pet Care: с заботой о питомцах не содержит рекламы.

В текущей версии приложения не используются сторонние рекламные или аналитические SDK для отслеживания поведения пользователей в рекламных целях.

Безопасность

Для передачи данных между приложением и серверными сервисами используются защищённые сетевые соединения.

Доступ к облачным данным пользователя привязан к его аккаунту.

Несмотря на принимаемые меры, ни один способ хранения или передачи данных через интернет не может гарантировать абсолютную безопасность.

Удаление аккаунта и данных

Удалить аккаунт можно непосредственно в Pet Care: с заботой о питомцах через настройки аккаунта.

При удалении аккаунта удаляются аккаунт приложения Pet Care: с заботой о питомцах и данные пользователя, хранящиеся в облачной базе Pet Care: с заботой о питомцах и связанные с этим аккаунтом.

Локальные данные на устройстве при удалении аккаунта не удаляются. Они хранятся только на устройстве, и разработчик не имеет возможности удалить их удалённо.

Чтобы удалить локальные данные, можно очистить данные приложения Pet Care: с заботой о питомцах средствами операционной системы или удалить приложение.

Если приложение больше недоступно, запросить удаление аккаунта можно на странице: legal.petcare-app.ru/delete-account/.

Отдельные технические записи и резервные копии у поставщиков инфраструктуры могут храниться ограниченное время в соответствии с их политиками хранения данных и применимыми требованиями законодательства.

Обращения в поддержку

Если вы обращаетесь по адресу support@petcare-app.ru, мы получаем ваш email и информацию, которую вы самостоятельно укажете в сообщении.

Эти данные используются только для обработки обращения.

Не отправляйте в службу поддержки пароль от аккаунта.

Изменения политики

Политика конфиденциальности может обновляться при изменении функций Pet Care: с заботой о питомцах или используемых сервисов.

Актуальная версия публикуется по адресу: legal.petcare-app.ru/privacy/.

Контакты

По вопросам конфиденциальности, обработки или удаления данных: support@petcare-app.ru.
