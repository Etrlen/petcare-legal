# Legal site — Pet Care: с заботой о питомцах

Перед публикацией:

1. Откройте `privacy/index.html`.
2. Developer name: `etrlen`.
3. Support email: `support@petcare-app.ru`.
4. Загрузите содержимое этой папки в репозиторий GitHub Pages.
5. В GitHub: Settings → Pages → Deploy from a branch → `main` / `/ (root)`.
6. В Custom domain укажите `legal.petcare-app.ru`.
7. В DNS REG.RU добавьте CNAME для `legal`, указывающий на `<ваш-github-логин>.github.io`.
8. После выпуска сертификата включите Enforce HTTPS.
